# Programación 4to Año 🐍🎮

Bienvenidos/as a la materia de Programación. En este curso vamos a aprender **Python desde cero** y vamos a cerrar el año armando **nuestro propio videojuego**.

## 📋 Descripción general

El curso se divide en dos grandes etapas:

1. **Fundamentos de Python** (introducción a la programación)
2. **Proyecto final: Videojuego** (aplicamos todo lo aprendido)

---

## 🧩 Etapa 1 — Introducción a Python

Contenidos que vamos a ver, en orden:

- [ ] ¿Qué es programar? Instalación de Python y primer programa
- [ ] Variables y tipos de datos (`int`, `float`, `str`, `bool`)
- [ ] Entrada y salida de datos (`input()`, `print()`)
- [ ] Operadores (aritméticos, de comparación, lógicos)
- [ ] Estructuras condicionales (`if`, `elif`, `else`)
- [ ] Bucles (`while`, `for`)
- [ ] Listas
- [ ] Tuplas
- [ ] Funciones (parámetros, retorno, alcance de variables)
- [ ] Strings y sus métodos
- [ ] **Diccionarios** (cierre de la etapa introductoria)

Cada tema se acompaña de ejercicios prácticos y pequeños desafíos para consolidar lo aprendido antes de avanzar al siguiente.

---

## 🎮 Etapa 2 — Programando un videojuego

Una vez que tengamos sólidas las bases de Python, vamos a poner manos a la obra con el desarrollo de un videojuego simple. Algunos de los temas que se suman en esta etapa:

- Introducción a la librería que usemos para el juego (por ejemplo `pygame`)
- Manejo de eventos (teclado, mouse)
- Dibujo de elementos en pantalla (sprites, formas, texto)
- Detección de colisiones
- Lógica de puntaje, vidas y niveles
- Sonidos y música (opcional)
- Armado final del proyecto y presentación
